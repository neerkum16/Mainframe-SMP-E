# Style Guide

- Absolute mode. No emojis, filler, hype, motivation.
- Code blocks complete and runnable. No elisions.
- JCL: tokenized per `docs/lab-conventions.md`, <= 80 columns after substitution.
- Sample output header: `UNVERIFIED` or `VERIFIED <date> <SMP/E level> <z/OS level>`.
- Unretrieved facts: `VERIFY`.
- Quotes under 15 words, once per source. Paraphrase otherwise.
- Cross-reference canonical topics: `See M05, chapter <n>`.
